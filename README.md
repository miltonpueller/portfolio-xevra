# Portfolio Web — Xevra

Módulos, herramientas e integraciones web desarrolladas a medida para el ecosistema de **Xevra**.

## 🚀 Demos en vivo

* 📊 **[Calculadora de Rentabilidad](https://miltonpueller.github.io/portfolio-xevra/calculadora-rentabilidad/)**
  Calculadora interactiva para proyectar costos, márgenes de ganancia y retorno de inversión en proyectos digitales.

* 📄 **[Generador de CV ATS](https://miltonpueller.github.io/portfolio-xevra/generador-cv/)**
  Herramienta de maquetación de currículums estructurada para superar filtros de selección automatizados (ATS). Procesa y almacena los datos 100% en el navegador por privacidad.

* 💼 **[Sistema de Presupuestos](https://miltonpueller.github.io/portfolio-xevra/sistema-presupuestos/)**
  Cotizador dinámico para calcular tarifas de servicios y desarrollo web en tiempo real.

---

## 🛠️ Tecnologías y Enfoque
* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Chart.js, jsPDF.
* **Ecosistema CMS:** Modificaciones y snippets en PHP y CSS para WordPress, Spectra y WooCommerce.
